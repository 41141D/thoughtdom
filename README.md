# ThoughtDom

A place for anonymous ideas, honest discussions, and understanding before disagreement.

## The Problem

Modern platforms reward:
- outrage
- popularity
- identity wars

ThoughtDom explores a different approach:

Freedom + Understanding.

## Features

- Anonymous pseudonymous identity
- Steel-Man Gate
- Idea-based reputation
- Threaded discussions
- Markdown posts
- Image support

## Tech Stack

Frontend:
- Next.js
- TypeScript
- Tailwind

Backend:
- FastAPI
- SQLAlchemy
- PostgreSQL (planned)
